Rules enforced beyond the schema

Services enforce current role and ownership, stock reservations, one default address, delivered-purchase review eligibility, no self-votes, upload ownership, safe saved-item transfers and permitted order-state transitions. Decimal prices and immutable order snapshots keep historical purchases accurate. File bytes live in a separate persistent media directory.

There is no real payment, shipment, refund, notification or variant model in this college demo. One order has one shared status; mixed-vendor fulfilment is handled by an administrator.
